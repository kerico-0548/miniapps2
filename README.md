# Клякса — Telegram Mini App

Статический каталог детской художественной мастерской. Работает как обычный сайт и внутри Telegram. Сборка, npm и сервер не требуются.

## Перед публикацией

1. Откройте `config.js`: замените `name` на название мастерской и укажите `telegramUsername` администратора **без @**. Кнопки откроют чат в Telegram с подготовленным текстом. Сообщение отправляет сам посетитель.
2. Описания занятий — предложенный текст, согласуйте его с реальной программой. При необходимости измените `index.html` и `courses` в `app.js`. Возраст для гончарного круга, цены, расписание, адрес, материалы и обжиг не указаны, так как этих данных пока нет.
3. Номер мастерской задаётся в `config.js` в поле `phone`. Он отображается в разделе контактов и в окне связи, если Telegram-контакт не указан. Номер добавлен в предоставленном виде: +8-968-555-555. Форма записи и хранение заявок не используются.

## GitHub Pages

1. Создайте репозиторий на GitHub и загрузите `index.html`, `style.css`, `app.js`, `config.js` и `.nojekyll` в его корень. README можно загрузить вместе с ними. Фотографии из исходной папки приложению не нужны.
2. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Выберите ветку `main`, каталог `/ (root)`, нажмите **Save**.
4. Дождитесь публикации. Адрес проекта обычно имеет вид `https://USERNAME.github.io/REPOSITORY/`. Все локальные пути относительные, поэтому приложение работает и в подкаталоге репозитория.

## Подключение к Telegram

1. В Telegram откройте официальный `@BotFather`, создайте бота командой `/newbot`, если своего бота ещё нет.
2. Через `/mybots` выберите бота. В **Bot Settings → Menu Button** (или командой `/setmenubutton`) задайте название кнопки, например «Наши занятия», и HTTPS-адрес опубликованного GitHub Pages.
3. При желании настройте Main Mini App через **Bot Settings → Configure Mini App**.
4. Откройте бота в Telegram и проверьте кнопку меню. Приложение использует официальный Telegram WebApp SDK, вызывает `ready()` и `expand()`, поддерживает кнопку «Назад» для окон с описанием.

Токен бота не нужен для этого каталога. Не размещайте его в репозитории и браузерном коде. Для автоматического приёма заявок ботом понадобится отдельная серверная часть.

Документация: https://core.telegram.org/bots/webapps

## Локальный просмотр

Откройте `index.html` в браузере. Для просмотра через HTTP из папки проекта можно выполнить `python -m http.server 8000`, затем открыть `http://localhost:8000`.

## Зависимости

Telegram SDK загружается с `telegram.org`, шрифт Golos Text — из Google Fonts. Если шрифт недоступен, используется Arial. Без Telegram SDK каталог продолжает работать в браузере. Иллюстрации сделаны на CSS, внешние изображения не используются.
